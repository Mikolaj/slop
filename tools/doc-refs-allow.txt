# Paths and build targets a document may name although they are not in
# ~/slop, read by tools/check-doc-refs.py. One glob per line; a line
# starting with "make " or "cabal " allows a target instead of a path.
# Text after "#" is the reason, and the reason is the point of the entry:
# an unexplained line here silently hides real drift, which is exactly
# what the checker exists to catch. When a named artifact lands, delete
# its entry rather than leaving it.
#
# Adding an entry is also the easy way to silently defang the checker, so
# re-run its docstring's non-vacuity test after touching this file.
#
# `.mcp.json` is a name whose existence depends on who is looking: the inner
# sandbox bind-mounts /dev/null over eleven dotfile names in the session's
# own working directory, which is ~/slop (CLAUDE.md's sandboxing notes),
# so `os.path.exists` returns True from a sandboxed session rooted here
# and False from an unsandboxed run. Pinning it makes the verdict the same
# everywhere. Of the eleven only this one needs it -- the rest carry no
# extension this checker treats as a path, so they stay unclassified.
.mcp.json
# Two files written in a working checkout, by Claude Code and by cabal, and
# ignored by git, so a fresh clone lacks them; pinned, as `.mcp.json` is, so
# that the verdict is the same in both.
.claude/settings.local.json
dist-newstyle/cache/plan.json
